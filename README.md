# 💕 Приглашение на Свидание (Date Invitation App)

Романтичное веб-приложение для приглашения на свидание с интерактивным интерфейсом. Приложение создано для Бишкека с локальными опциями мест и активностей.

## ✨ Возможности

- 💬 **Интерактивное приглашение** - "Ты пойдешь со мной на свидание?"
- 🔄 **Вторая попытка** - Если ответ "Нет", приложение просит еще один шанс
- 📅 **Выбор даты** - Календарь для выбора удобной даты
- 🕐 **Выбор времени** - Временной выбор
- 📍 **Выбор места** - 4 основные категории:
  - ☕ **Кафе** - Выбор кухни (Итальянская, Азиатская, Грузинская, Русская и т.д.)
  - 🚶 **Прогулка** - Выбор места в Бишкеке (Парк Панфилова, Площадь Ала-Тоо, Озеро Иссык-Куль и т.д.)
  - 🎬 **Кино** - Выбор жанра фильма
  - 🍽️ **Ресторан** - Выбор кухни
- 🎫 **Билет на свидание** - Красивый итоговый билет со всеми выбранными данными
- 📥 **Скачивание** - Возможность скачать билет как картинку
- 📤 **Поделиться** - Поделиться билетом в социальные сети или скопировать в буфер обмена

## 🚀 Как использовать

1. Откройте `index.html` в вашем браузере
2. Нажмите "Да! ✨" на вопрос "Ты пойдешь со мной на свидание?"
3. Выберите дату свидания
4. Выберите время встречи
5. Выберите место и тип активности
6. Сделайте финальный выбор (кухня, жанр, район и т.д.)
7. Получите красивый билет на свидание
8. Скачайте или поделитесь билетом!

## 📱 Функции

### Стадии приложения

1. **Стадия 1**: Главный вопрос - "Ты пойдешь со мной на свидание?"
2. **Стадия 2**: Вторая попытка (если первый ответ "Нет")
3. **Стадия 3**: Выбор даты
4. **Стадия 4**: Выбор времени
5. **Стадия 5**: Выбор места (основные категории)
6. **Стадия 5a-5d**: Дополнительные опции в зависимости от выбора
7. **Стадия 6**: Финальный билет на свидание
8. **Стадия 7**: Отказ (если ответ "Нет" во второй раз)

## 🔐 Приватность

Приложение полностью работает на клиентской стороне. Никакие данные не отправляются на сервер. Все выбранные данные хранятся только в браузере пользователя.
